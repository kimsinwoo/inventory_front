# CJ대한통운 업로드 양식

## 📄 파일 정보

**파일명**: `CJ대한통운_업로드_양식.xlsx`

이 파일은 CJ대한통운 택배사에 업로드하기 위한 표준 양식입니다.

## 🎯 용도

### 프론트엔드
- 배송 관리 페이지 (`/shipping/nav2`)에서 사용자가 다운로드할 수 있습니다
- 백엔드가 생성해야 하는 파일 형식의 참고 자료입니다

### 백엔드
- `POST /api/shipment/cj/generate` 엔드포인트에서 이 양식에 맞춰 엑셀 파일을 생성해야 합니다
- 입력: 자사몰, 쿠팡, 스마트스토어 주문 엑셀 파일
- 출력: CJ 대한통운 업로드 양식에 맞춘 통합 엑셀 파일

## 📋 주요 필드 (예상)

CJ 대한통운 업로드 양식은 일반적으로 다음 필드를 포함합니다:

- 받는분 성명
- 받는분 전화번호
- 우편번호
- 주소
- 상세주소
- 품목명
- 수량
- 배송 메시지
- 송장번호 (자동 생성)

## 🔧 백엔드 구현 가이드

### 1. 엑셀 파일 읽기
각 채널(자사몰, 쿠팡, 스마트스토어)의 엑셀 파일을 읽어 주문 정보를 추출합니다.

### 2. 데이터 병합 및 정제
- 중복 주문 제거
- 동일 수령인의 여러 품목을 하나의 배송으로 통합
- 주소 형식 정규화
- 전화번호 형식 정규화

### 3. CJ 양식에 맞춰 엑셀 생성
- 이 양식 파일의 컬럼 순서와 형식을 따릅니다
- 마감 태그 추가 (예: [자사몰 15:00마감])
- 송장번호는 빈 칸으로 남겨둡니다 (CJ 시스템에서 자동 생성)

### 4. 에러 리포트 생성 (선택)
처리 중 발생한 오류를 별도의 엑셀 파일로 생성합니다.

## 📊 응답 형식

### JSON 응답
```json
{
  "ok": true,
  "downloadUrl": "/downloads/cj_upload_20250129.xlsx",
  "errorReportUrl": "/downloads/errors_20250129.xlsx",
  "summary": {
    "orders_parsed": 150,
    "orders_aggregated": 120
  }
}
```

### 바이너리 응답
```
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment; filename="CJ_업로드_통합.xlsx"
```

## 🔗 관련 파일

- 프론트엔드: `src/pages/Shipping.jsx`
- API 문서: `SHIPPING_SETUP_GUIDE.md`

## 📝 참고사항

1. **채널별 마감 시간**
   - 자사몰: 15:00
   - 쿠팡: 16:00
   - 스마트스토어: 17:00

2. **파일 형식**
   - 입력: `.xlsx` 또는 `.xls`
   - 출력: `.xlsx` (CJ 양식)

3. **보안**
   - 고객 개인정보 포함 → 접근 권한 관리 필수
   - HTTPS 사용 권장
   - 생성된 파일은 일정 시간 후 자동 삭제 권장

## 🚀 테스트 방법

1. 프론트엔드에서 테스트 주문 파일 업로드
2. 생성된 CJ 파일 다운로드
3. 이 양식 파일과 비교하여 형식 확인
4. CJ 시스템에 실제 업로드 테스트 (운영 전)
